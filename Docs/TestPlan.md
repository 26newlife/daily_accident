# 테스트 시나리오 문서 (TestPlan)

7분 안에 모든 루트·사망 경로를 매번 처음부터 플레이하기 어렵기 때문에, **F10 디버그 패널**로 Act·루트·상태를 점프하면서 확인한다.
디버그 도구는 에디터/개발 빌드(`UNITY_EDITOR || DEVELOPMENT_BUILD`)에서만 동작한다.

## 0. 준비

1. `Tools > GameUI > Build Apartment Scene` 실행 (GameScene·Player 프리팹·데이터 에셋 재생성). 읽히는 기존 에셋은 보존되고 새 에셋만 추가된다.
   - **중요**: 예전 빌드가 남긴 "읽을 수 없는 자리표시 에셋"(목표 / 엔딩 / 점수 / 사망 사유 일부)은 이번 실행에서 Console 에
     `[ApartmentBuilder] 읽을 수 없는 에셋을 지우고 다시 만듭니다: ...` 로 표시되며 새로 만들어진다 (원인: ScriptableObject 5종이 한 파일에 있어 에디터를 다시 열면 연결이 끊김 → 파일 분리로 해결).
     두 번째 실행부터는 이 경고가 나오지 않아야 한다.
2. `Tools > GameUI > Debug > Run Full Audit` → Console 의 `[Audit] ... PASS/FAIL` 확인 (FAIL 0 이어야 함).
3. (선택) `Tools > GameUI > Debug > Run Runtime Smoke Test` → 자동으로 플레이 모드에 들어가 재시작 5회·Act 3~4·루트 A~D·엔딩·타임아웃을 점검하고 `smoke_results.txt` 에 결과를 남긴다.
4. 수동 테스트는 GameScene 을 직접 재생 (에디터에서 `allowDirectPlayInEditor`) 하고 **F10** 으로 패널을 연다. 패널이 열려 있는 동안 커서가 풀리고 이동이 멈춘다.

### 디버그 패널 사용법 (F10)

| 항목 | 설명 |
|---|---|
| Act jump 1~4 | 선행 조건(정전, 폭발 기록, 불, 플래그)을 채우고 해당 Act 로 점프. 예약 타이머는 비운다 |
| Handle HOT / NORMAL | `act3_front_door_blocked` 와 복도 불을 설정 (뜨거움 → 루트 B/C, 정상 → 복도 대피) |
| stairwell_down_blocked / early | 다음 점프에 적용할 계단 상태 (Act 3 점프 후에는 "Apply stair flags now") |
| Force route A/B/C/D | Act 4 에서 루트를 강제로 확정 |
| Give item | 젖은 수건 / 수건 / 소화기 / 청테이프 / 옥상 열쇠 / 망치 / 생수 |
| Fire / Smoke / Gas 슬라이더 | 불 크기, 전역 연기, 가스 농도 |
| NPC state | 할머니(동행·방치·눌러대기·쓰러짐), 청년(동행·달려감) |
| Refill breath / Invulnerable | 호흡기 회복, 무적(테스트용, 사망 판정 무시) |
| 상단 상태 줄 | Run #, 게임 시각, 현재 Act/step, **활성 타이머 수 / EventBus 구독 수(기준값 대비)**, 루트 옵션, NPC 상태 |

`Timers active` 와 `EventBus subs` 는 씬 진입 1초 후의 값을 baseline 으로 잡아 둔다. 재시작 후에도 같은 시점의 값이 baseline 과 같아야 한다.

## 5. Act 4 — 루트 (F10 → Act 4 / Force route)

루트는 행동으로 확정된다: `stairs_up` → A, 칸막이 타격 → B, 대피공간 문 닫기/문틈 밀봉 → C, `stairs_down` → D.
`RouteResolver` 는 가능한 루트를 안내만 하며 선택을 막지 않는다. 불가능한 루트를 고르면 결과(연기 질식 등)가 나온다.

## 6. 엔딩 화면 (A4-E2 / E3)

- 엔딩 이름 + 루트 라벨, 설명, **구조 점수 14개 항목 점수**, 등급(S/A/B/C), 소요 시간, **잘한 점 / 아쉬운 점**(교육 피드백), 엔딩 모음(생존·사망), `다시 시작`·`메인 메뉴` 버튼.
- 히든 엔딩: 할머니를 동행(`FollowingPlayer`)하거나 구출한 채 어느 생존 엔딩이든 도달 → `ending_hidden_grandmother`.

## 7. 알려진 제한 (수동 확인 필요)

- 새 구역(계단참·옥상·1003호·집결지)은 **그레이박스**다. 실제 화면에서 겹침/가시성은 Scene 뷰로 확인할 것.
- 모든 소리·영상 슬롯은 비어 있다 (클립 연결 전에도 에러 없이 동작).
- 통로 검증(`Validate Apartment Clearance`): 변경 전(HEAD)에도 있던 **5건 FAIL**(베란다→대피공간 방화문 병목 0.88m / 침실→창문 앞 동쪽 통로 / window_kitchen 앞 침범 / window_kitchen 시선 / pickup_key 시선(DeskChair))은 그대로이며 새로 늘어난 FAIL 은 없다. 검증기는 NPC·계단참·옥상·집결지·1003호 안쪽 현관을 대상에서 제외한다(압축 이동 구역).
